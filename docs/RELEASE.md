# Rudy MountLens 0.1.0 preview

Offline C11 inspection and comparison of Linux mountinfo captures. Inspect parent links, direct mount stacks, propagation markers and effective restrictions, or compare snapshots with an optional relaxation gate.

The Windows x64, Linux x64, and macOS ARM64 archives include the native executable, a runnable sample, and build documentation. Compare the archive digest with its entry in the SHA-256 manifest.
